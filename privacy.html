StereoPilot Backup

Privacy policy

Effective date: October 23, 2026.

Purpose and information used

StereoPilot Backup is a personal backup utility. With the account owner's authorization, rclone uses the Google Drive API to upload selected files, list application-created files and folders, read their metadata and checksums, download them, and remove owner-selected application-created files.

The OAuth scope is https://www.googleapis.com/auth/drive.file. The utility does not request general access to unrelated existing Drive files.

Storage and transfer

Backup files are stored in the owner's Google Drive and on computers selected by the owner. OAuth credentials are stored on the owner's server. Transfers use HTTPS and may pass through a network proxy configured by the owner. This information website does not receive backup files or OAuth credentials.

Use and disclosure

Google data is used to perform backup, verification, restoration, and file management requested by the owner. It is not sold or used for advertising. This website has no analytics, advertising, or third-party scripts.

The utility's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Files remain in their selected storage locations until the owner deletes them. The owner can revoke authorization through Google Account connections and remove local credentials. Revoking authorization does not itself delete existing backup files.
