StereoPilot Backup

A personal backup utility operated by the account owner using rclone on a Linux server.

The utility uploads owner-selected backup files to the owner's Google Drive and downloads files for integrity checks or restoration.

Google Drive access

The requested OAuth scope is https://www.googleapis.com/auth/drive.file. It allows the utility to manage files and folders created by this application. Access requires the account owner's Google authorization.

This information website has no login or upload form and does not request passwords, OAuth tokens, or backup contents.
